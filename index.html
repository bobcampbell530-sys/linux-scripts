Screenshot

ImageClipper

GUI screenshot tool — clipboard or file

A lightweight screenshot utility that lets you select a screen region with your mouse, then saves the capture to the clipboard (for pasting) or as a timestamped PNG file in ~/Pictures/Screenshots/.

Download ZIP

Dependencies

  • imagemagick (import command)
  • xclip (clipboard operations)
  • zenity (GUI dialogs)
  • libnotify-bin (notifications)
Launcher Manager

launcher_v3

GUI launcher creator and manager

A graphical tool to create, edit, and delete desktop launchers. Select any executable script, name it, add an icon, and it automatically creates the symlink, .desktop file, and adds it to your application menu.

Download ZIP

Dependencies

  • zenity (GUI dialogs)
  • update-desktop-database
OCR

ocr_multi

Screen region OCR — text to clipboard

Capture a screen region and extract text using Tesseract OCR. Choose from 6 languages, select the area, and the recognized text is copied to your clipboard automatically.

Download ZIP

Dependencies

  • tesseract-ocr + language packs
  • gnome-screenshot (region capture)
  • xclip (clipboard)
  • zenity + libnotify-bin
Audio Recorder

quickaudio_v3

System/mic/headphones audio recorder

A GUI audio recorder that captures system audio, microphone, or a mix as MP3 files. Choose your audio source, set an optional timer, name the file, and run again to stop recording. Saves to ~/Video/Audio/.

Download ZIP

Dependencies

  • ffmpeg (recording & MP3 encoding)
  • zenity (GUI dialogs)
  • pulseaudio-utils (pactl)
  • libnotify-bin (notifications)
Video Recorder

QuickVid_v7

Draggable-area screen video recorder

A GUI screen video recorder that lets you select a draggable area on screen to record. Choose your audio source (system, mic, headphones, or mixed), set an optional timer, and record in MP4 format at 30 FPS. Run again to stop. Saves to ~/Videos/.

Download ZIP

Dependencies

  • ffmpeg (video encoding H.264/AAC)
  • slop (area selection)
  • zenity (GUI dialogs)
  • pulseaudio-utils (pactl)
  • libnotify-bin (notifications)
